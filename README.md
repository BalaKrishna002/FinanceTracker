# Finance Tracker (Track your finances)

- This is a simple backend to track our everyday finances (DEBIT/CREDIT)
- Here is the frontend code [FinanceTracker-FE](https://github.com/BalaKrishna002/FinanceTracker-FE)

## Current Project Features:
- User can register(fullName, email, password, currency and timezone) & login(email and password) which generates JWT token
- User Add transactions has been done at any time with a date-time picker and see all the transactions for specified from and to epochTimeStamp
- The user can delete one transaction each time, with the ID
- user can get aggregated credit/debit amount for month/year

## New Feature under development:
- Email notification system to send USER_WELCOME when a new user is registered
- Email notification to send each with the previous month's total debit & credit amount(MONTHLY_SUMMARY)
